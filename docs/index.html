⚡ What Happens Behind the Scenes?

  • 1
    You tap or type from anywhere

    Use Telegram or the Android companion app over Wi-Fi or cellular. The Android app connects through your HTTPS relay.

  • 2
    MacBook receives via Long-Polling

    The host receives commands through short outbound HTTPS polls. No router firewall openings, static IPs, or VPNs are required.

  • 3
    Host app handles approved actions

    Built-in actions use an allowlist. Coding-agent prompts wait for approval on the computer before running.

  • 4
    Direct Delivery to Your Phone

    Command status and results return to your phone. The relay is not end-to-end encrypted; host it only on infrastructure you trust.

System Architecture

No inbound ports are needed. The phone and host connect to your HTTPS relay. Relay traffic is not end-to-end encrypted, so use infrastructure you trust.

Start with MacRemote

Use the terminal-first Mac host and private local dashboard, or build the optional desktop and Android previews.

Recommended

Install the terminal-first Mac host

Copy this single command. It installs the Mac host and opens the local setup dashboard—no repository clone, build commands, or extra terminal steps.

brew update && brew install --force ard-tube/mac-remote-agent/macremote && macremote start

The dashboard opens on this Mac and stays available while you set up a connection. Phone control requires HTTPS relay credentials; this project does not currently operate a public relay. The dashboard listens only on 127.0.0.1, and coding-agent requests still require local approval.

macOS

Optional native menu-bar app preview

Use a Mac with macOS 13+, Swift 5.9+, and Python 3 installed.

swift build --package-path macos --configuration release && bash macos/build-app.sh

Open dist/MacRemote.app. This optional preview is not Developer ID signed or notarized, so macOS Gatekeeper may block downloaded copies.

Windows

Package the desktop and tray app

Build from Windows with Python 3.9+ and PowerShell:

.\windows\build-app.ps1

The package is written to dist\MacRemote-Windows.zip. Verify the preview on a Windows machine before relying on it.

Android

Build the companion APK

Use Java 17, Android SDK 35, and Gradle 8.9:

cd android && gradle --no-daemon :app:assembleDebug

This creates a debug APK. First deploy the relay behind HTTPS, then pair using its host ID and the phone token. See relay setup and security notes.
